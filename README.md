PLAN (Personal & Logistical Action Network) is a multi-user task and 
to-do management system built in OS/VS COBOL (IKFCBL00) and JCL for IBM 
MVS 3.8j (TK5) under the Hercules emulator. Designed around a shared VSAM
 KSDS master repository, it provides both interactive 3270 transaction 
screens via KICKS and direct TSO/batch command-line utilities for 
managing personal and shared tasks across TSO user accounts, complete 
with automated nightly GDG archiving, VSAM reorganization, and daily 
action sheet reporting.
